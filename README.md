## Creation-of-Figma-Account
Creating a figma account with 2-3 pages for user login using vs code  
## Figma Clone - Created Using VS Code :
I created a Figma Account using only HTML, CSS, and JavaScript in VS Code. I did not use figma.com. I recreated the Figma design in code. The project name is MyApp. It is a simple and clean Figma Account flow. It looks like a real design with three screens, input boxes, buttons, and clear messages for the user.

## 3 Screens
1. Screen 1 - Welcome: MyApp logo, Welcome to MyApp text, Design your ideas, Get Started button, Already have account Login text.
2. Screen 2 - Create Account: Full Name input, Email Address input, Password input, Sign Up button, Back button, error message area.
3. Screen 3 - Success: Success heading, Hello Your account is ready message, Back to Home button.

## STEPS:
Step 1: Open VS Code on your system.
Step 2: Open project folder figma-account
Step 3: Open file index.html.
Step 4: Right-click index.html and click Open with Live Server.
Step 5: If Live Server is not there, double-click index.html to open in Chrome.
Step 6: You will see Welcome Screen. Click Get Started.
Step 7: Now you will see Create Account Screen. Fill Name, Email, Password.
Step 8: Click Sign Up. If input is wrong, error will show
